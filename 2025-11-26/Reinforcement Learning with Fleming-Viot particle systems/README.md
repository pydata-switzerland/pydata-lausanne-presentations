# Reinforcement learning accelerated with Fleming-Viot particle systems: a parallel correlated system simulation with restarting

In the Fleming-Viot particle system framework, each particle represents a copy of the system which is simulated in regions that are rarely visited by the system's dynamics.

In this way, information that is potentially important for the optimization problem tackled with reinforcement learning may be gathered faster than under the normal system behaviour, thus accelerating learning.

The method is illustrated in the dimensioning of stochastic networks and queues, such as e.g. servers.
